# Screenshots

The main `README.md` references the following PNGs from this folder. Drop the
files here with these exact names and the README renders them on GitHub:

| File                | What to capture |
|---------------------|------------------|
| `card.png`          | The `custom:openlitter-card` on a Lovelace dashboard with the globe rotating and a cat present (pills green). |
| `device.png`        | Settings → Devices & Services → OpenLitter → device, showing all entities listed (state, weight, cycle count, buttons, update). |
| `logbook.png`       | Settings → Logbook filtered to the OpenLitter device, showing a cycle + cat visit sequence. |
| `config-flow.png`   | The initial setup dialog after clicking the mDNS discovery toast, with the Host / Port / MQTT options visible. |
| `reconfigure.png`   | Settings → Devices & Services → OpenLitter → Configure, showing the reconfigure dialog. |
| `statistics.png`    | Settings → Dashboards → Energy/Statistics, or any chart card pointing at `sensor.openlitter_cycle_count` showing the per-day bars. |

Recommended size: 1200–1600 px wide PNGs. Crop tightly — GitHub will downscale.
